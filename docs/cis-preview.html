Editorial Network CIS v0.1 規格預覽

這一頁是靜態、離線可看的 CIS 樣本頁。它用 canonical token 畫出 Forum 與 Adventurers Guild 兩種產品表面，並示範共用元件。沒有外部資源、沒有建置步驟、沒有即時資料。

檔案位置：docs/cis-preview.html；token 來源：docs/cis/tokens.css。全部內容標示為規格樣本（specimen／demo）。

Canonical source note（規格來源聲明）

這個 forum repository 的 docs/cis/ 是 CIS 的唯一母來源（canonical source of truth）。Adventurers Guild 只會消費之後同步或產生的輸出（synchronized outputs），不自行維護第二份母來源。

The forum repository is the canonical CIS source. The Adventurers Guild consumes synchronized outputs later. Nothing on this page claims the two live sites already look the same.

本頁所有內容都是規劃樣本，不是對正式站台現況的宣告。

Mobile navigation 行動導覽

在 48rem 以下，頁首導覽收合成單一「選單」按鈕；展開後是整列可點項目，觸控目標至少 44px。把瀏覽器縮到 320px 寬即可看到。
